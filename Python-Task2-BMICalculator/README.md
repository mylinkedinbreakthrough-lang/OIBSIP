# BMI Calculator

A simple Python-based BMI Calculator developed as part of the Oasis Infobyte Python Internship.

## Features

- Accepts weight in kilograms (kg)
- Accepts height in meters (m)
- Calculates Body Mass Index (BMI)
- Rounds the BMI result to two decimal places
- Categorizes the BMI result as:
  - Underweight
  - Healthy weight
  - Overweight
  - Obese
- Handles non-numeric inputs
- Rejects zero and negative weight or height values

## Formula

BMI is calculated using:

BMI = Weight (kg) / Height² (m²)

## Technology Used

- Python

## How to Run

Run the `BMI_calculator.py` file using a Python interpreter.

The program will ask the user to enter their weight and height, then calculate and display their BMI and corresponding category.
