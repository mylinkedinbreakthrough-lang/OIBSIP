# Random Password Generator

A simple Python-based Random Password Generator developed as part of the Oasis Infobyte Python Internship.

## Features

- Allows the user to specify the desired password length
- Generates passwords using uppercase and lowercase letters
- Includes numbers and special characters
- Randomly selects characters from the available character pool
- Generates a password with the exact length specified by the user
- Validates the password length to prevent zero or negative values

## How It Works

The program asks the user to enter a desired password length.

It then combines:

- Uppercase and lowercase letters
- Digits
- Special characters

The program randomly selects characters from this pool until the requested password length is reached.

## Technology Used

- Python

## How to Run

Run the `Random_password_generator.py` file using a Python interpreter.

Enter the desired password length when prompted, and the program will generate and display a random password.
